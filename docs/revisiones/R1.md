# Revisión R1 · Pedidos de venta (F1)

Guion de la revisión con la operación al cerrar F1 (spec 003, FR-032, C-T009). Recorre US1 a US4 con los usuarios de ejemplo. En cada paso dice qué debe confirmar la operación y deja un renglón para sus pedidos de ajuste.

Los ajustes se pasan después a "Exploración y cambios" de la spec 003, o a la spec de la fase que tocan si llegan después del cierre. Este guion no decide nada: lo que cambie el diseño va a `docs/diseno/decisiones.md`.

## Antes de la sesión

1. Levantar todo con el bridge simulado:

   ```bash
   ./run.sh --with-bridge
   ```

   Compila, aplica las migraciones, pasa las pruebas y deja la web en `http://localhost:9000`. En desarrollo, la API siembra los usuarios de R1 (tabla de abajo) con la contraseña `LOCAL_R1_PASSWORD` de `.env.local`. La del Administrador es `LOCAL_ADMIN_PASSWORD`.
2. Como `sistemas`, en Configuración › Sincronización, pulsar **Sincronizar todo**. Todos los catálogos deben quedar en `Éxito`.
3. Crear pedidos de ejemplo para las listas (sección 4):

   ```bash
   scripts/dev/sembrar-pedidos.sh 500
   ```

4. Tener abiertos dos navegadores, o una ventana normal y una privada, para entrar con dos usuarios a la vez.
